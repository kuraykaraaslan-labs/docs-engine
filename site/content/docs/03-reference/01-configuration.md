# Configuration

`defineDocsConfig` validates the config with zod and throws one error listing every
problem, so a typo fails the build. Unknown keys are rejected.

## `site`

| Key | Default | |
|---|---|---|
| `title` | required | Wordmark text and the `%s | title` metadata template |
| `tagline`, `description` | | Home page and metadata |
| `url` | required | `metadataBase` and canonical URLs |
| `locale` | `en` | `<html lang>` |
| `logo` | | `{ src?, alt?, text?, href = '/' }`; or pass a `logo` node to `DocsShell` |

## `navbar`

```ts
navbar: {
  themeToggle: true,
  items: [
    { label: 'Docs', href: '/docs' },                                   // left by default
    { label: 'GitHub', href: 'https://github.com/x', position: 'right' },
    { type: 'slot', name: 'search', order: -1 },                        // right by default
  ],
},
```

A link is active on its own path and everything under it. External links
(`http(s)://`, or `external: true`) open in a new tab. A `slot` renders the node you
pass in `DocsShell`'s `navbarSlots[name]`: search boxes, account menus and anything
else that needs code. `order` positions an item within its side.

## `footer`

`{ links?, copyright?, version? }`, rendered with kui's `AppFooter` by `DocsFooter`.

## `collections`

Optional (default `[]`): a host can use only the shell and the markdown pipeline.

| Key | Default | |
|---|---|---|
| `id` | required | `a-z0-9-` |
| `dir` | required | Folder of `.md` files, relative to the app root |
| `routeBasePath` | `docs` | URL prefix; `''` mounts at the root |
| `sidebar` | autogenerated | Name of an entry in `sidebars` |
| `editUrl` | | Base of the "Edit this page" link; the file path is appended |

## `sidebars`, `toc`, `theme`

- `sidebars`: see [Sidebars](/docs/authoring/sidebars).
- `toc`: `{ minDepth = 2, maxDepth = 3 }` for "On this page".
- `theme`: `{ defaultMode = 'system' }`, passed to `DocsThemeProvider`.
