# Sidebars

## Generated from folders

A collection with no `sidebar` gets one generated from its folder tree:

- each folder is a category; its `index.md` (or `README.md`) becomes the
  category's own page,
- order is `sidebar_position`, then the `position` in `_category_.json`, then the
  number prefix, then the name.

```json title="content/docs/01-getting-started/_category_.json"
{ "label": "Getting Started", "position": 1, "collapsed": false, "link": "getting-started/overview" }
```

`_category_.yml` works too.

## Listed by hand

Point the collection at a named sidebar and list it in `sidebars`:

```ts title="docs.config.ts"
collections: [{ id: 'docs', dir: 'content/docs', sidebar: 'main' }],
sidebars: {
  main: [
    'index',
    {
      type: 'category',
      label: 'Guides',
      link: 'guides/index',
      items: ['guides/writing', { type: 'autogenerated', dir: 'guides/advanced' }],
    },
    { type: 'link', label: 'Changelog', href: 'https://github.com/kuraykaraaslan-labs/docs-engine/releases' },
  ],
},
```

An unknown doc id fails the build. Previous / next links follow the sidebar order.

> [!NOTE]
> A top-level category becomes a collapsible group of kui's `AppSidebar`; deeper
> categories nest inside it, behind a disclosure toggle. The branch holding the
> current page opens by itself, and sidebar links navigate client-side through
> `next/link` (pass `clientNavigation={false}` to `DocsShell` for full page loads).
