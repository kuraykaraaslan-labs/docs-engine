# Changelog

All notable changes to this project will be documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- Sidebars nest: categories below the top level are nested kui `AppSidebar` items with
  disclosure toggles instead of being flattened into their group.
- Sidebar links navigate client-side through `next/link`; `DocsShell`'s
  `clientNavigation={false}` restores plain anchors.
- The phone-only navbar links in the sidebar header hide from `md` up through
  `AppSidebar`'s `headerClassName`, replacing a `matchMedia` workaround.
- kui components re-vendored at kui-react 26e1d97 (AppSidebar nesting, `renderLink`,
  slot wrapper classes).
- `collections` is optional (default `[]`), for hosts that use only the shell and the
  markdown pipeline.

## [0.1.0] - 2026-10-22

### Added

- `defineDocsConfig`: zod-validated site, navbar (links and named slots, left/right,
  ordered), footer, collections, sidebars, table of contents and theme settings.
- Collection loader: frontmatter (Docusaurus keys, unknown keys kept), titles from
  frontmatter or the leading `# Heading`, number-prefix ordering, `slug` overrides,
  drafts, `_category_.json` / `.yml`, duplicate id and URL detection.
- Sidebars autogenerated from folders or listed by hand (docs, links, categories,
  autogenerated sections); prev/next in sidebar order with per-doc overrides.
- Markdown pipeline: GFM, `> [!KIND]` callouts with titles, `:::kind` admonitions,
  heading ids with `{#custom-id}`, highlight.js, code source stashing, host remark
  and rehype plugins.
- Block splitter with a fence-plugin registry, lifted callout blocks and
  whitespace-run control for hosts with persisted block ids.
- UI: `DocsShell` (kui AppShell/AppSidebar/AppTopBar, mobile navbar in the drawer),
  `DocPage` (TOC, edit link, pager), `BlockRenderer`, `CodeBlock`, `MermaidBlock`,
  `DocsFooter`, `ThemeToggle`, `DocsThemeProvider`.
- `createDocsRoutes` and `siteMetadata` for the App Router.
- `styles.css` (Tailwind `@source`) and `theme.css` (kui design tokens).
- Documentation site in `site/`, built with the engine.
