# Agent notes

- **Ships source, not a build.** Hosts compile `src/` through `transpilePackages`.
  Use relative imports only: a `@/` alias here would resolve against the host's.
- **Server/client boundary.** `src/content` and `src/markdown` read the filesystem
  and import `yaml`/`zod`. A `'use client'` file may import them with `import type`
  only. After a site build, `grep -rl YAMLParseError site/.next/static/chunks/`
  must print nothing.
- **kui copies.** `src/ui/kui/` is generated by `scripts/vendor-kui.mjs` from
  kui-react (`$KUIREACT_ROOT`). Never edit it; fix kui-react and re-vendor. A
  component missing from kui-react is built there first.
- **Known consumer.** learn (`kuraykaraaslan/learn-platform`) runs the pipeline with
  `headingIds: false`, `callouts: { titles: false }`, no admonitions and
  `keepWhitespaceRuns: true`, and gates on a byte-identical render snapshot of 412
  lessons. Changing what those options produce breaks its gate.
- **Verify** with `npm test`, `npm run typecheck` and `npm run site:build`.
- Next.js 16: read `node_modules/next/dist/docs/` before using an API from memory.
